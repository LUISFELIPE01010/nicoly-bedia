## UI and assets
- Keep the legacy chrome-gold token and brand token mapped to the same global CSS variable so existing site and CRM controls share the current accent color.
- Catalog procedure photographs are illustrative local assets imported by the catalog data module; do not describe generated devices as verified branded equipment or generated scenes as patient results.
- Serve responsive WebP derivatives of site photographs while preserving original assets; source selection must avoid downloading hidden desktop hero imagery on mobile.
- Load catalog and CRM screens on demand so their code does not increase the public homepage's initial download.
- Isolate the existing catalog/export rendering in a legacy view and legacy treatment component; screen-only catalog redesigns must not change the PDF or hidden export experience.
- Keep catalog icon mappings in a slug-indexed data module, separate from procedure content, so web and future print designs can share them.
